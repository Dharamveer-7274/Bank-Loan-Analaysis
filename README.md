# Bank-Loan-Analaysis
# 🏦 Bank Loan Data Analytics Portfolio Project

This project demonstrates an end-to-end data analytics workflow using **SQL, Power BI, Power Query, DAX, and Excel** to analyze bank loan data and generate actionable business insights. The dashboard helps monitor loan performance, evaluate portfolio health, identify risky loans, and support data-driven decision-making.

---

# 📌 Project Overview

The objective of this project is to transform raw loan data into meaningful business intelligence by performing data cleaning, analysis, visualization, and reporting.

### ✅ Data Cleaning & Transformation (Power Query)
- Cleaned and transformed raw loan data.
- Prepared the dataset for analysis and reporting.

### ✅ Data Analysis (SQL & DAX)
- Analyzed loan applications, funded amounts, repayments, loan quality, interest rates, and customer segments.
- Created KPIs and calculated business metrics using DAX.

### ✅ Interactive Dashboard (Power BI)
- Built a three-page interactive dashboard featuring:
  - Executive Summary
  - Business Overview
  - Loan Details
- Included dynamic filters, KPIs, maps, trend analysis, and customer segmentation.

### ✅ Business Insights
- Evaluated Good vs Bad Loans.
- Identified loan application trends by state, purpose, employment length, and home ownership.
- Generated insights to support better lending and portfolio management decisions.
